# 使用手册（日常怎么用）

## 我要连什么

| 项 | 值 |
|---|---|
| 网关地址（OpenAI 兼容） | `http://127.0.0.1:3000/v1` |
| 网关地址（Anthropic，Claude Code 用） | `http://127.0.0.1:3000` |
| API Key | 见运维台「连接信息」表，或部署机 `data/ops/.generated-creds.txt` 的 `GATEWAY_KEY` |
| 模型名 | **`free-chat`**（聊天/生图/生视频都用这一个名字，不用切） |

## 客户端怎么配

**用 CC Switch 接 Claude Code**（推荐）：
1. 新建 provider，类型选 Claude；
2. Base URL 填 `http://127.0.0.1:3000`；
3. API Key 填网关 key；
4. 保存切换到该 provider 即可。

**其他 OpenAI 兼容工具**（Cherry Studio、LobeChat、脚本等）：
- Base URL：`http://127.0.0.1:3000/v1`
- API Key：网关 key
- Model：`free-chat`

**curl 直测**：
```bash
curl -s http://127.0.0.1:3000/v1/chat/completions \
  -H "Authorization: Bearer <网关key>" \
  -H "Content-Type: application/json" \
  -d '{"model":"free-chat","messages":[{"role":"user","content":"你好"}]}'
```

## 三种能力怎么调

调用哪个由**客户端/模型按任务自动选端点**，你只写同一个模型名：

| 你要做的事 | 走的端点 | 背后 |
|---|---|---|
| 聊天 / 写代码 / 推理 / 查资料 | `/v1/chat/completions` | 五家池按权重分流 |
| 生成图片 | `/v1/images/generations` | 豆包 Seedream 优先 → GLM CogView 兜底 |
| 生成视频 | `/v1/videos/generations` | GLM CogVideoX 优先 → 豆包兜底 |

## 背后有哪些家（能力与代价）

| 渠道 | 类型 | 擅长 | 注意 |
|---|---|---|---|
| 智谱 GLM-5.3 网页版 | 网页逆向 | 对话/检索/生图/生视频 | 生视频有每日积分上限 |
| DeepSeek 网页版 | 网页逆向 | 对话/工具/推理 | **无联网检索**；封号阶梯 1/3/8天→永久 |
| 智谱 GLM-4.7-Flash 官方 | 官方 API | 对话/工具 | 永久免费；高峰偶发 1305 限流（会自动跳别家） |
| Kimi 网页版 | 网页逆向 | 对话/检索 | **每 3 小时 30 轮**长文本，重度用会耗光 |
| 豆包 网页版 | 网页逆向 | 对话/生图 | 登录态 7–14 天过期（最短） |

权重：官方 Flash(50) > GLM/DeepSeek 网页(40) > Kimi/豆包(35)。某家失败 → 自动禁用 → 重试下一家 → 恢复后自动回池。

## 常见期望管理

- **响应慢**：网页逆向路线天然比官方 API 慢；遇到慢的那次可能是落到了网页版渠道。官方 Flash 权重最高就是为了缓解这点。
- **风格会变**：背后是多模型轮换，同一问题不同次可能由不同模型回答，措辞会有差异——这是"多平台分摊"的固有代价。
- **联网检索不是每次都有**：只有 GLM/Kimi 支持；若某次回答说"我无法联网"，重发一次可能就落到支持检索的渠道。

## 出问题先看这里

打开 **http://127.0.0.1:3000/ops/**（运维台），看四家/五家的状态灯：

| 灯色 | 含义 | 你该做什么 |
|---|---|---|
| 🟢 正常 | 运行正常 | 无需操作 |
| 🔴 凭证过期 | 该平台登录态失效 | 照 `credentials-guide.md` 重新取凭证，在运维台粘贴 |
| 🟡 限流/风控 | 撞限流了 | 等一会；别反复重试 |
| ⚪ 积分不足 | 生图/生视频额度用完 | 等次日恢复 |
| 🟠 适配器报错 | 该家坏了 | 看详情；常见是协议改动，需更新适配器 |

运维台每行都有「更换凭证」按钮，粘贴保存后自动重启对应适配器。更细的运维操作见 `operations.md`。
